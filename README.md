Question 1: Reverse a String

Function

def reverse_string(text: str) -> str:

Description

Returns the reverse of the given string.

Approach

I traverse the string character by character and construct the reversed
string by adding each character to the beginning of the result.

Example

Input:  hello
Output: olleh

Question 2: Count Vowels

Function

def count_vowels(text: str) -> int:

Description

Counts the total number of vowels in the given string.

Vowels Considered

a, e, i, o, u

Both uppercase and lowercase vowels are counted.

Approach

I iterate through each character in the string and check whether it is a
vowel. The character is converted to lowercase for case handling. If the
character is a vowel, the count is increased by one.

Example

Input:  Hello World
Output: 3

Edge Cases

The solution handles basic cases mentioned in the assessment,
including: - Empty strings - Uppercase and lowercase characters -
Strings with no vowels - Spaces and non-vowel characters
